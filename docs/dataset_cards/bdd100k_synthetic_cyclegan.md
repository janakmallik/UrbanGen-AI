
# Dataset Card — BDD100K Synthetic Night (CycleGAN)

## Overview
Synthetic nighttime residential images generated by the Method 2 CycleGAN model. Created by translating real BDD100K daytime images into nighttime versions.

## Provenance
- **Source images:** Real BDD100K daytime residential images from the train split
- **Generator:** ``outputs/method_2_resume/checkpoints/epoch_20.pth``
- **Generation script:** ``scripts/method_2_generate_synthetic.py``
- **Generation date:** 2026-11-10
- **Random seed:** 42
- **Source selection:** 500 daytime residential images, excluding all Method 2 reserved splits (day_train 1,500 + day_holdout 200 + night_train 1,500 + night_holdout 200 = 3,400 reserved)

## Content
- **Daytime source images:** 500 from the BDD100K train split (excluding Method 2 splits)
- **Generated candidates:** 500
- **Accepted by automated filters:** 282 (56.4% survival)
- **Output resolution:** 512×288
- **Label:** Each output inherits the source image's label (residential, nighttime)

## Automated filters used
Three filters were applied at generation time:

| Filter | Threshold | Rejections |
|---|---|---|
| CLIP night score | > 0.50 | 5 |
| Luminance | < 0.20 | 5 |
| Paved surface fraction | within ±0.10 of source | 208 |

**Known limitation:** These filters were later found to be unreliable. See ``docs/findings.md`` "The filter failure" section. The 282 accepted images contain ~15-25% structural failures (near-black output, smeared structure) that passed the filters. Manual curation is required before using this dataset for Arm D training.

## Intended use
- Training data for the Arm D classifier (real + synthetic augmentation)
- Not for direct evaluation. Synthetic images must never enter the test set.

## Known limitations
- Small resolution (512×288). Not usable for segmentation or detection tasks.
- Filters unreliable — need manual curation before training
- Not photorealistic. Visual inspection required before use.
- Cannot be used to validate Week 5 classifier improvements (circularity — must use real test set).
- Generated from daytime residential sources only. Does not cover city street or highway scenes.
