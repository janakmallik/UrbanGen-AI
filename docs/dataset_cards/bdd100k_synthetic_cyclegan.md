
# Dataset Card — BDD100K Synthetic Night (CycleGAN)

## Overview
Synthetic nighttime residential images generated by the CycleGAN model trained in Method 2. Created by translating real BDD100K daytime images into nighttime versions.

## Provenance
- **Source images:** Real BDD100K daytime residential scenes from the train split
- **Generator:** ``outputs/method_2_resume/checkpoints/epoch_20.pth``
- **Generation script:** ``scripts/method_2_generate_synthetic.py`` (to be written)
- **Generation date:** TBD
- **Random seed:** 42

## Content
- **Daytime source images:** 500 from the original training set (excluding holdout)
- **Output:** 500 synthetic nighttime images at 512×288
- **Label:** Each output inherits the source image's label (residential, daytime in reality, but with nighttime appearance)

## Quality filters
Every synthetic image is validated against four thresholds:
1. **CLIP night score > 0.50** (semantic nighttime appearance)
2. **Luminance < 0.20** (dark enough to be night)
3. **SSIM > 0.40** (structural preservation vs source)
4. **SegFormer road fraction within ±0.10** of source (road layout preserved)

Images failing any filter are rejected. Expected survival rate: 70-90% based on Method 2 pilot.

## Intended use
- Training data for the Arm D classifier (real + synthetic augmentation)
- Not for direct evaluation. Synthetic images must never enter the test set.

## Known limitations
- Small resolution (512×288). Not usable for segmentation or detection tasks.
- Some purple artifacts may remain in the sky.
- Not photorealistic. Visual inspection recommended before use.
- Cannot be used to validate Week 5 classifier improvements (circularity — must use real test set).
