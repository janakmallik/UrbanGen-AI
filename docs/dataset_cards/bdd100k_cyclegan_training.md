
# Dataset Card — BDD100K CycleGAN Training Splits

## Overview
Train/holdout splits used to train the Method 2 CycleGAN model. Documentation of the exact images used, so the trained model can be reproduced and evaluated on independent data.

## Source
- **Dataset:** BDD100K (Yu et al., CVPR 2020)
- **Root:** ``URBANINTEL_DATA_ROOT/bdd100k``
- **Split:** train (the labeled training partition of BDD100K)
- **Classes:** residential only (scene == "residential")
- **Time of day:** daytime and night only (excludes dawn/dusk, undefined)

## Splits

| Split | Count | Purpose |
|---|---:|---|
| **day_train** | 1,500 | Daytime residential images used to train CycleGAN's day→night generator |
| **night_train** | 1,500 | Nighttime residential images used to train CycleGAN's night→day generator |
| **day_holdout** | 200 | Daytime residential images never seen in training (for evaluation) |
| **night_holdout** | 200 | Nighttime residential images never seen in training |
| **Total** | 3,400 | |

All four splits are pairwise disjoint. Verified by ``method_2_generate_synthetic.py --dry-run``.

## Selection method
1. Load ``bdd100k_labels_images_train.json``
2. Filter to `scene == "residential"` and `timeofday in {"daytime", "night"}`
3. Sort by filename
4. Sample 1,700 day + 1,700 night with `random.Random(42)`
5. First 1,500 of each become the training split
6. Last 200 of each become the holdout split

## Manifest
The split manifest is at ``outputs/method_2_resume/split_manifest.json``. It contains:
- `day_train`: list of 1,500 filenames
- `night_train`: list of 1,500 filenames
- `day_holdout`: list of 200 filenames
- `night_holdout`: list of 200 filenames

## Provenance verification
- Original 500 training images (from ``epoch_05.pth``) reconstructed via seed-42 sample of the pre-resume pool
- Verified to be a subset of `day_train`
- Verified that `day_train[500:]` has zero overlap with the original 500
- All four splits verified disjoint by 6-pair overlap check

## Known limitations
- BDD100K labels have some noise (timeofday mislabeling is documented in `docs/label_audit/`). ~5% of images may be mislabeled, based on visual inspection of samples.
- Only residential scenes are included. CycleGAN is not trained for city street or highway translation.
- Each BDD100K image is a single keyframe (10th second of a 10-second video), not a video sequence.

## Reproduce
Training splits are generated by:
``````powershell
uv run python scripts/method_2_cyclegan_resume.py
``````

The split is deterministic (seed 42), so re-running will produce identical splits.
